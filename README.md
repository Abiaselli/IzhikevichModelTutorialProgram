# IzhikevichModelTutorialProgram
Izhikevich Model Tutorial Program (Web-page version)

This is an HTML version of the tutorial program available at https://www.izhikevich.org/publications/whichmod.htm for students who do not have access to Matlab. Electronic version of the figures included and reproduction permissions are freely available at www.izhikevich.com, as well as the original Matlab tutorial program.
